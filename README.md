# E-Commerce Sales Analysis | SQL Portfolio Project

A completed SQL analysis project exploring e-commerce sales, product performance, customer purchasing behaviour, order trends, and payment patterns using MySQL 8+.

> **Dataset note:** The original project dataset was unavailable when this portfolio copy was assembled. The CSV files included here are synthetic replacement data created for demonstration and reproducibility. They should not be presented as the original dataset or as real company transactions.

## Project overview

The analysis is organised around practical business questions:

- How much revenue was generated by delivered orders?
- Which products and categories contributed the most revenue?
- How did revenue change month by month?
- Who were the highest-spending and repeat customers?
- What were the cancellation and return patterns?
- Which payment methods and customer locations were most represented?
- Which products had the highest estimated gross profit?

## Dataset contents

| File | Description |
|---|---|
| `customers.csv` | Customer profile and location information |
| `products.csv` | Product catalogue, category, selling price and synthetic unit cost |
| `orders.csv` | Order date, customer and order status |
| `order_items.csv` | Products purchased, quantity, discounts and line totals |
| `payments.csv` | Payment date, method, status and amount |

The dataset contains 600 customers, 24 products, 1,800 orders, 3,005 order-item records and 1,800 payment records.

See [DATA_DICTIONARY.md](DATA_DICTIONARY.md) for table and column descriptions.

## SQL techniques demonstrated

- Relational database design and primary/foreign keys
- INNER JOIN and LEFT JOIN
- Aggregations, `GROUP BY` and `HAVING`
- Subqueries and Common Table Expressions (CTEs)
- Window functions: `RANK()`, `ROW_NUMBER()`, `LAG()` and cumulative `SUM()`
- Date-based analysis and month-over-month comparisons
- Revenue, average order value, repeat customer and order-status analysis
